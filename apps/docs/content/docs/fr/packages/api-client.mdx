Un fin wrapper autour de `fetch` avec des méthodes typées pour l'API Routess.

## Exports

| Point d'entrée | À utiliser pour |
| --- | --- |
| `@routess/api-client` | Factory du client, adaptateurs, services et types de l'API |

## Utilisation

```ts
import { createApiClient } from "@routess/api-client";

const api = createApiClient({ baseUrl: import.meta.env.VITE_API_URL });

const me = await api.getProfile();
const routes = await api.getRoutes();
```

## Gestion des erreurs

Toutes les méthodes du client lèvent `ApiError` sur les réponses non-2xx. L'erreur inclut :

- `status` : code de statut HTTP
- `code` : code d'erreur lisible par une machine, renvoyé par l'API
- `message` : lisible par un humain
- `fieldErrors?` : pour les erreurs de validation 422
