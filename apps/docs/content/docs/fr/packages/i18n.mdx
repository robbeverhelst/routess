Un petit service i18n indépendant du framework et réutilisé entre le web et le mobile.

## Langues prises en charge

- Anglais (`en`), la langue par défaut
- Néerlandais (`nl`)
- Français (`fr`)
- Allemand (`de`)

## Utilisation

```ts
import { createI18nService } from "@routess/i18n";
import { logger } from "@routess/core";

const i18n = createI18nService(logger);

i18n.setLocale("nl");
i18n.t("nav.signIn"); // → "Inloggen"
i18n.t("greeting", { name: "Robbe" }); // → "Hallo, Robbe!"
```

## Structure des locales

```
packages/i18n/src/locales/
├── en.ts
├── nl.ts
├── fr.ts
└── de.ts
```

Chaque locale exporte un objet plat de clés.

## Ajouter une clé

1. Ajoute la clé à **chaque** fichier de locale (commence par `en.ts`)
2. Utilise `i18n.t("your.key")` dans le code
3. Les types TypeScript se mettent à jour automatiquement ; les traductions manquantes apparaissent comme des erreurs de type

## Ajouter une locale

1. Ajoute `xx.ts` dans `src/locales/` avec toutes les clés traduites
2. Enregistre la locale dans la factory du service
3. Ajoute la langue au `i18n.ts` du site de documentation si tu veux aussi des traductions du Guide utilisateur
