title: Voraussetzungen
description: Tools, die du lokal installiert haben musst.
---

| Tool | Version | Wofür |
| --- | --- | --- |
| Bun | 1.3+ (das Repo pinnt die exakte Version in `package.json` → `packageManager`) | Workspace-Paketmanager + Runtime |
| Docker | latest | Lokales Postgres + Image-Builds |
| Node | 24.x | Einige Build-Tools (Vite, Next) benötigen Node; CI und die Docker-Images nutzen Node 24 |
| Git | latest | Versionsverwaltung |

## Installation

```sh
# macOS
brew install oven-sh/bun/bun
brew install --cask docker
brew install node@24

# verify
bun --version
docker --version
node --version
```

## Optional

- **Helm 3.16+**: um den Chart lokal zu validieren
- **kubectl**: um auf ein Cluster zu deployen
- **VS Code + Biome-Extension**: beste Dev-UX
