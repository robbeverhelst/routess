Ein kleiner i18n-Dienst, der frameworkunabhängig ist und über Web und Mobile hinweg wiederverwendet wird.

## Unterstützte Sprachen

- Englisch (`en`), der Standard
- Niederländisch (`nl`)
- Französisch (`fr`)
- Deutsch (`de`)

## Nutzung

```ts
import { createI18nService } from "@routess/i18n";
import { logger } from "@routess/core";

const i18n = createI18nService(logger);

i18n.setLocale("nl");
i18n.t("nav.signIn"); // → "Inloggen"
i18n.t("greeting", { name: "Robbe" }); // → "Hallo, Robbe!"
```

## Aufbau der Locales

```
packages/i18n/src/locales/
├── en.ts
├── nl.ts
├── fr.ts
└── de.ts
```

Jede Locale exportiert ein flaches Objekt mit Keys.

## Einen Key hinzufügen

1. Füge den Key zu **jeder** Locale-Datei hinzu (beginne mit `en.ts`)
2. Nutze `i18n.t("your.key")` im Code
3. Die TypeScript-Typen aktualisieren sich automatisch; fehlende Übersetzungen tauchen als Typfehler auf

## Eine Locale hinzufügen

1. Füge `xx.ts` in `src/locales/` mit allen übersetzten Keys hinzu
2. Registriere die Locale in der Service-Factory
3. Füge die Sprache zur `i18n.ts` der Docs-Seite hinzu, wenn du auch Übersetzungen des Benutzerhandbuchs möchtest
