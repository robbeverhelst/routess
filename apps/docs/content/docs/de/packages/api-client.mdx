title: "@routess/api-client"
description: HTTP-Client für die Routess-API.
---

Ein dünner Wrapper über `fetch` mit typisierten Methoden für die Routess-API.

## Exports

| Einstiegspunkt | Nutze ihn für |
| --- | --- |
| `@routess/api-client` | Client-Factory, Adapter, Services und API-Typen |

## Nutzung

```ts
import { createApiClient } from "@routess/api-client";

const api = createApiClient({ baseUrl: import.meta.env.VITE_API_URL });

const me = await api.getProfile();
const routes = await api.getRoutes();
```

## Fehlerbehandlung

Alle Client-Methoden werfen bei Nicht-2xx-Responses ein `ApiError`. Der Fehler enthält:

- `status`: HTTP-Statuscode
- `code`: maschinenlesbarer Fehlercode aus der API
- `message`: menschenlesbar
- `fieldErrors?`: für 422-Validierungsfehler
