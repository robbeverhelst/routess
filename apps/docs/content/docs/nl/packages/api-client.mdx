Een dunne wrapper rond `fetch` met getypeerde methodes voor de Routess-API.

## Exports

| Entrypoint | Gebruik het voor |
| --- | --- |
| `@routess/api-client` | Client-factory, adapters, services en API-types |

## Gebruik

```ts
import { createApiClient } from "@routess/api-client";

const api = createApiClient({ baseUrl: import.meta.env.VITE_API_URL });

const me = await api.getProfile();
const routes = await api.getRoutes();
```

## Foutafhandeling

Alle clientmethodes gooien `ApiError` bij niet-2xx-responses. De fout bevat:

- `status`: HTTP-statuscode
- `code`: machineleesbare foutcode van de API
- `message`: leesbaar voor mensen
- `fieldErrors?`: voor 422-validatiefouten
