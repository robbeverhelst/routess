De repo heeft een testsuite die bij elke PR draait.

## Frameworks

| Onderdeel | Framework |
| --- | --- |
| Web (`apps/web`) | bun test + happy-dom + React Testing Library + MSW |
| Web-E2E (`apps/web/e2e`) | Playwright, API en Stripe nagebootst in de browser |
| API (`apps/api`) | bun test + Postgres-testcontainer |
| Packages | bun test |

## Uitvoeren

```sh
bun run test                    # All tests across the workspace
bun run --filter './apps/web' test
bun run --filter './packages/*' test
bun run test:e2e                # Playwright browser E2E (apps/web)
```

## Conventies

- Testbestanden staan naast de broncode: `foo.ts` + `foo.test.ts`
- Webtests gebruiken **MSW** om de API op netwerkniveau te mocken (geen module-mocks van de api-client)
- API-tests draaien tegen een echte Postgres in CI (Docker service container), geen gemockte DB

## Coverage

Web heeft `bun test --coverage` (`bun run test:coverage`) ingericht. CI gate niet op coverage; het is een richtlijn, geen regel.
