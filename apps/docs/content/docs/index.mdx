These docs are for **people building, deploying, or contributing to Routess**. If you're using the app, head to the [User Guide](/en/guide) instead.

## What's here

- **[Getting Started](/docs/getting-started/local-setup)** — Clone the repo and run it locally
- **[Architecture](/docs/architecture/overview)** — How the pieces fit together
- **[Apps](/docs/apps/web)** — `apps/web`, `apps/api`, and the planned mobile app
- **[Packages](/docs/packages/core)** — The `@routess/*` workspace packages
- **[Operations](/docs/operations/docker)** — Docker, Kubernetes, security, CI/CD
- **[Contributing](/docs/contributing/coding-standards)** — Coding standards, testing, releases

## Tech stack at a glance

- **Web** — React 19, Vite, TanStack Router, Mapbox GL, Zustand, Tailwind v4
- **API** — NestJS 11, MikroORM, PostgreSQL
- **Tooling** — Bun, Biome, semantic-release, Helm, GitHub Actions
