---
title: Prerequisites
description: Tools you need installed locally.
---

| Tool | Version | Why |
| --- | --- | --- |
| Bun | 1.4+ (repo pins the exact version in `package.json` → `packageManager`) | Workspace package manager + runtime |
| Docker | latest | Local Postgres + image builds |
| Node | 24.x | Some build tools (Vite, Next) run on Node locally; the web, docs and landing Docker images build on Node 24 (CI runs on Bun) |
| Git | latest | Source control |

## Install

```sh
# macOS
brew install oven-sh/bun/bun
brew install --cask docker
brew install node@24

# verify
bun --version
docker --version
node --version
```

## Optional

- **Helm 3.16+**: to validate the chart locally
- **kubectl**: to deploy to a cluster
- **VS Code + Biome extension**: best dev UX
