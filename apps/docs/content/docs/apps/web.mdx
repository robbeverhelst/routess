The web app is a single-page application built with **React 19**, **Vite 8**, and **Mapbox GL 3**.

## Structure

```
apps/web/
├── src/
│   ├── components/    # Map, sidebar, controls
│   ├── routes/        # TanStack Router routes
│   ├── lib/           # Web-specific glue
│   ├── hooks/         # React hooks
│   └── main.tsx       # Entry
├── public/            # Static assets
├── nginx.conf         # Production server config
├── entrypoint.sh      # Runtime env injection
├── Dockerfile         # Multi-stage build → nginx
└── vite.config.ts
```

## Key dependencies

| Library | Why |
| --- | --- |
| `mapbox-gl` + `react-map-gl` | The map |
| `@tanstack/react-router` | Type-safe routing with code-split routes |
| `@tanstack/react-query` | Server state caching |
| `zustand` | Client state (from `@routess/core`) |
| `tailwindcss` v4 | Styling, themed via `@routess/design-tokens` |
| `@radix-ui/*` | Headless UI primitives |
| `@react-oauth/google` | Google sign-in button |

## Runtime configuration

The Dockerfile builds with **placeholder values**. At container start, `entrypoint.sh` substitutes the real values from environment variables into the built JS files. This lets one image be promoted across environments without rebuilding.

## Scripts

```sh
bun run dev              # Vite dev server
bun run build            # Production build
bun run preview          # Preview the production build locally
bun run test             # Vitest
bun run check-types      # tsc --noEmit
```
