The API is a **NestJS 11** application persisting to PostgreSQL via **MikroORM 6**.

## Structure

```
apps/api/
├── src/
│   ├── auth/          # Google OAuth + JWT
│   ├── users/         # User CRUD (self-only)
│   ├── routes/        # Route CRUD
│   ├── health/        # /health/live, /health/ready
│   ├── config/        # Env validation, MikroORM config
│   └── main.ts        # Entry
├── migrations/        # MikroORM SQL migrations
└── Dockerfile
```

## Public endpoints

For full request/response shapes, see the [API Reference](/api-reference).

| Method | Path | Auth |
| --- | --- | --- |
| POST | `/api/v1/auth/google` | none |
| GET | `/api/v1/auth/me` | cookie |
| POST | `/api/v1/auth/logout` | cookie |
| GET / PATCH / DELETE | `/api/v1/users/me` | cookie |
| GET / POST / PATCH / DELETE | `/api/v1/routes(/:id)` | cookie |
| GET | `/health/live`, `/health/ready` | none |
| GET | `/metrics` | none (internal-only via NetworkPolicy) |

## Environment variables

See `apps/api/.env.example`. Required at runtime:

- `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD`, `DB_NAME`
- `JWT_SECRET`
- `GOOGLE_CLIENT_ID`
- `GOOGLE_CLIENT_SECRET`
- `NODE_ENV`, `PORT`

## Observability

The API exposes Prometheus-style metrics at `/metrics` and emits OpenTelemetry traces (configurable via `OTEL_*` env vars).
