
## Workspace dependencies

Apps depend on packages via `workspace:*`:

```json
{
	"dependencies": {
		"@routess/core": "workspace:*",
		"@routess/i18n": "workspace:*"
	}
}
```

Bun resolves these to the local package — no publishing needed.
