---
title: Prerequisites
description: Tools you need installed locally.
---

| Tool | Version | Why |
| --- | --- | --- |
| Bun | 1.3.11 | Workspace package manager + runtime |
| Docker | latest | Local Postgres + image builds |
| Node | 20.x | Some build tools (Vite, Next) require Node |
| Git | latest | Source control |

## Install

```sh
# macOS
brew install oven-sh/bun/bun
brew install --cask docker
brew install node@20

# verify
bun --version
docker --version
node --version
```

## Optional

- **Helm 3.16+** — to validate the chart locally
- **kubectl** — to deploy to a cluster
- **VS Code + Biome extension** — best dev UX
