---
title: What's new
description: Where to follow routess releases and changes.
---

routess ships continuously: every merged improvement is released automatically with a version number and release notes.

- **Release notes**: the [GitHub releases page](https://github.com/robbeverhelst/routess/releases) lists every version with its changes.
- **Follow along**: watch the [GitHub repository](https://github.com/robbeverhelst/routess) to get notified about new releases.

Self-hosting? Pin a specific version with the `ROUTESS_TAG` variable; see [Developer Docs → Self-host](/docs/operations/self-host).
