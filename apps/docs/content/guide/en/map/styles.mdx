routess offers a few built-in map styles you can switch between.

> _Screenshot placeholder: style switcher menu._

## Available styles

- **Streets** — default detailed street view
- **Outdoors** — terrain-focused, useful for hiking
- **Satellite** — aerial imagery
- **Dark** — low-light friendly

The selected style is remembered across sessions.
