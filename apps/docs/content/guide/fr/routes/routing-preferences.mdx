Ouvrez les **Préférences d'itinéraire** depuis l'icône de curseurs en haut du panneau de planification, ou via la palette de commandes (`Ctrl/Cmd + K`). Les préférences sont enregistrées sur votre appareil et appliquées lorsque vous cliquez sur **Appliquer**.

## Profils

Choisissez le profil qui correspond à la sortie à vélo ou à la course que vous souhaitez :

- **Le plus rapide** : le profil par défaut ; l'itinéraire le plus direct et le plus sensé
- **Pittoresque** : accepte jusqu'à environ 15 % de temps en plus pour de plus belles routes
- **Le plus sûr** : privilégie les pistes cyclables et les rues calmes
- **Plat** : évite les côtes dans la mesure du possible

## Réglage fin

Sous le profil, vous pouvez activer des préférences individuelles :

- **Préférer les infrastructures cyclables** : favorise les pistes et bandes cyclables
- **Éviter les montées raides** : contourne les pentes, avec un curseur **Pente de montée maximale (%)**
- **Éviter les chemins non revêtus** : reste sur les surfaces revêtues
- **Éviter les voies rapides** : exclut les segments d'autoroute
- **Aligner automatiquement les points de passage** : les points de passage déposés s'alignent sur la route la plus proche

**Réinitialiser** rétablit les valeurs par défaut. Après **Appliquer**, les nouveaux itinéraires et les recalculs utilisent vos réglages ; les segments existants ne changent pas tant que vous ne les modifiez pas.
