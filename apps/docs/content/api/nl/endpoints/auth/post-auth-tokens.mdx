---
title: Mint a personal access token
description: >-
  Creates a new PAT for the authenticated user. Returns the plaintext exactly
  once; it is hashed at rest and cannot be retrieved again. Tokens authenticate
  non-browser clients (CLI, AI agents, scripts) via `Authorization: Bearer
  routess_pat_…`. Minting is cookie-only: PATs cannot mint other PATs. PATs are
  blocked from `/v1/admin/*` and from `DELETE /v1/users/me` regardless of the
  owner's role.
